上传文件格式说明

格式 说明
JSON 单个报告对象、对象数组，或 {"reports": [...]} 包装。字段：exam_item / gender / age / finding / conclusion（兼容中文键名 检查项目/性别/年龄/超声所见/超声提示）。
CSV / TSV 首行为表头，列名使用上述字段名或中文键名即可自动映射；每行一份报告。
XLSX Excel/WPS 工作表，首行为表头（列名同 CSV），仅解析第一个工作表。
TXT / MD 多份报告按分隔行（如 ----------）或空行分隔；每份报告内使用「检查项目：」「超声所见：」「超声提示：」等标签行，无标签时全文按超声所见处理。

测试用例使用方法

  1. 免上传演示：切换到「测试数据集」页签 → 选择数据集 → 点击「一键纠错」，即可查看该数据集的完整纠错结果与问题定位。
  2. 上传演示：在「上传纠错」页签下载页面顶部的样例文件（JSON/CSV/TXT/XLSX 任一）→ 上传（可一次选多个文件）→ 预览解析结果 → 点击「开始纠错」。
  3. 预期效果：「正常报告集」应检出 0 条问题（零误报对照）；其余数据集的预期命中规则见数据集卡片上的说明。
  4. 结果导出：纠错完成后点击结果区「导出纠错结果（Excel）」按钮，即可下载含「质控概览 + 错误明细」两个 Sheet 的 Excel 文件。
  5. 模板库适配：规则库已对齐院内「明基超声模板重组」词库口径， 可检出模板占位符未替换（*侧 / *个 / mm×mm / 低回声/高回声 等斜杠选项）、分级体系与检查部位错配、腹部检查漏双肾等；数据集 「10 院内模板占位符适配」可直接演示。

HTTP 接口说明

方法 路径 说明
GET /api/health 服务状态、引擎版本、规则来源探针
GET /api/rules 查看当前生效的规则库
GET /api/datasets 预置测试数据集列表
GET /api/datasets/{id} 数据集详情（含报告列表）
POST /api/datasets/{id}/check 对预置数据集一键纠错
POST /api/check 单份报告纠错（标准 JSON 报告对象）
POST /api/check/batch 批量纠错：{"reports": [...]}
POST /api/export 导出纠错结果为 Excel（质控概览 + 错误明细）
POST /api/upload 上传并解析一个或多个文件（不纠错，供预览）
POST /api/upload/check 上传 → 解析 → 纠错，单请求返回完整结果

完整接口文档（请求/响应示例、curl 调用）见部署包内 README.md；亦可访问 /docs 查看自动生成的交互式 API 文档。
